# Production Voice Library

The library contains 24 selected cast voices plus the earlier `male_lead_01` test voice. All 24 cast voices have a canonical `neutral` reference. Six core voices additionally contain `gentle`, `angry`, `sad`, `panic`, and `whisper` references:

- `male_young_sunny_01`
- `male_young_cold_01`
- `male_mature_elite_01`
- `female_young_sweet_01`
- `female_young_cool_01`
- `female_mature_queen_01`

For ordinary dialogue, use controllable mode with `style=neutral` and an acting instruction,
including when a registered emotion reference exists. Use Ultimate with a registered emotion
only when deliberately reproducing its performance. Add a dedicated style reference after listening.

Production batch input is demonstrated in `configs/episode.production.example.json`.
Each new batch line is written to `outputs/raw/<project>/run_NNNN/<line_id>/candidate_01.wav`
with matching metadata. The revision manifest records every take and selection recommendation.

```bash
.venv/bin/python scripts/batch_dub.py configs/episode.production.example.json
```

Run the non-generative integrity audit at any time:

```bash
.venv/bin/python scripts/audit_voice_library.py
```

Raw audition takes remain under `outputs/raw/voice_cast_v1` and `outputs/raw/emotion_cast_v1`. Canonical references never replace those masters.

## Reference provenance and quality

Every enriched style records reference SHA-256, exact registered transcript and hash, duration,
sample rate, peak/RMS, clipping, silence and PASS/WARN/FAIL audio QC. Existing metadata values
are preserved; unknown historical source, date, model revision or commercial rights remain
unknown/null. A current model lock at registration is not proof that an external recording was
generated by that model. Commercial permission is never inferred from a file's presence.

```bash
.venv/bin/python scripts/enrich_voice_metadata.py          # read-only report
.venv/bin/python scripts/enrich_voice_metadata.py --write  # additive metadata + backup
```

Backups go under `outputs/qc/voice_metadata/`. The command never edits reference WAVs and refuses
to replace a previously recorded reference checksum if content changed. Portable voice metadata
stores reference paths relative to the character directory; generated local output metadata may
include absolute paths. Audio stays ignored by version control.

Prefer a clean 5–15-second single-performance reference, mono 48kHz, exact transcript, no clipping,
music or strong room sound. Existing short clips remain usable with visible warnings. Noisy/music/
reverberant recordings and transcript accuracy still require listening; see [QUALITY.md](QUALITY.md).

`create_voice.py` refuses an existing style directory, keeps the supplied original, validates
before PCM conversion, and adds a separately normalized reference. Use a new style/character ID
for a new canonical proposal. Do not auto-finalize audition selections or replace canonical voices
to make QC warnings disappear. Human candidate approval for an episode is separate from canonical
voice registration.
